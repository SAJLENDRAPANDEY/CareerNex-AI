## 🧠 Overview

**CareerNex AI** is a full-stack SaaS platform that combines the power of large language models with career intelligence to help professionals and students make smarter decisions about their careers.

Whether you're a fresh graduate overwhelmed by job options, a mid-career professional looking to upskill, or a developer preparing for technical interviews — CareerNex AI gives you a personalized, AI-driven co-pilot for every step of your career journey.

> 💡 *Think of it as a career mentor + resume expert + skill advisor — all in one intelligent platform.*

## 🚀 Getting Started

### Prerequisites

Make sure you have these installed:

```bash
node --version    # v18+ required (v20 recommended)
npm --version     # v9+
git --version
```

### 1. Clone the Repository

```bash
git clone https://github.com/SAJLENDRAPANDEY/CareerNex-AI.git
cd CareerNex-AI
```

### 2. Install Dependencies

```bash
# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install
```

### 3. Setup Environment Variables

Create `.env` files in both `frontend/` and `backend/` directories.

**Frontend** — `frontend/.env.local`
```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

**Backend** — `backend/.env`
```env
PORT=5000
GROQ_API_KEY=your_groq_api_key_here
```

> 🔑 Get your free Groq API key at [console.groq.com](https://console.groq.com)

### 4. Run the Application

**Start Backend Server:**
```bash
cd backend
npm run dev
# Server running at http://localhost:5000
```

**Start Frontend Dev Server:**
```bash
cd frontend
npm run dev
# App running at http://localhost:3000
```

### 5. Open in Browser

```
http://localhost:3000
```

## 📡 API Reference

Base URL: `https://careernex-ai.onrender.com`

---

### `POST /api/chat`
AI Career Coach conversation endpoint.

**Request Body:**
```json
{
  "message": "What skills should I learn to become a backend engineer?",
  "context": "I have 1 year of JavaScript experience"
}
```

**Response:**
```json
{
  "reply": "Based on your JavaScript background, I'd recommend...",
  "suggestions": ["Node.js", "PostgreSQL", "System Design"]
}
```

---

### `POST /api/resume-analyze`
Analyze a resume and return structured feedback.

**Request Body:**
```json
{
  "resumeText": "John Doe | Software Engineer | ...",
  "targetRole": "Senior Full Stack Developer"
}
```

**Response:**
```json
{
  "atsScore": 72,
  "strengths": ["Clear work history", "Quantified achievements"],
  "improvements": ["Add more keywords", "Improve summary section"],
  "missingKeywords": ["Docker", "CI/CD", "Microservices"]
}
```

---

### `POST /api/generate-roadmap`
Generate a personalized learning roadmap.

**Request Body:**
```json
{
  "goal": "Become a Machine Learning Engineer",
  "currentSkills": ["Python", "Statistics"],
  "timelineMonths": 6
}
```

**Response:**
```json
{
  "roadmap": [
    { "month": 1, "focus": "NumPy & Pandas", "resources": [...] },
    { "month": 2, "focus": "ML Algorithms", "resources": [...] }
  ]
}
```

---

### `POST /api/career-suggestions`
Get AI-powered career path recommendations.

**Request Body:**
```json
{
  "skills": ["React", "Node.js", "MongoDB"],
  "interests": ["building products", "startups"],
  "experience": "2 years"
}
```

**Response:**
```json
{
  "recommendations": [
    { "role": "Full Stack Developer", "matchScore": 94 },
    { "role": "Technical Co-Founder", "matchScore": 81 }
  ]
}
```

## ☁️ Deployment

### Frontend — Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/SAJLENDRAPANDEY/CareerNex-AI)

```bash
# From the /frontend directory
npx vercel --prod
```

Set environment variable in Vercel dashboard:
```
NEXT_PUBLIC_API_URL = https://careernex-ai.onrender.com
```

### Backend — Render

1. Go to [render.com](https://render.com) → **New Web Service**
2. Connect your GitHub repo
3. Set **Root Directory** to `backend`
4. Set **Build Command**: `npm install`
5. Set **Start Command**: `npm start`
6. Add environment variable: `GROQ_API_KEY = your_key_here`

> ⚠️ **Note:** Render free-tier services spin down after inactivity. The first request may take ~30 seconds to wake up.
